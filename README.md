# 🏮 Birthday Lantern Story

A magical, interactive birthday experience inspired by the iconic lantern scene from Tangled. This project is a mobile-first web application designed to tell a romantic story through drifting lanterns and interactive storytelling.

## ✨ Features

- **Parallax Starry Sky:** Multi-layered background stars that move at different speeds for astronomical depth.
- **Drifting Lanterns:** A sky filled with dozens of background lanterns that drift, sway, and pulse organically.
- **Interactive Story Snippets:** 16 cylindrical parchment lanterns that rise into view as you scroll, each containing a personal message.
- **Atmospheric Fireflies:** Subtle, blinking golden particles that float across the viewport.
- **Cinematic Boat Scene:** A highly detailed silhouette of Rapunzel and Flynn in a boat, set against the backdrop of Corona castle with radiant water reflections.
- **Musical Integration:** Fades in "I See the Light" smoothly on the first scroll gesture, with a dedicated music toggle.
- **Mobile-Optimized:** Built with touch-interaction and responsive scrolling in mind.

## 🛠 Tech Stack

- **Vue 3:** Composition API for logic and state.
- **GSAP (GreenSock Animation Platform):** Powering all complex scroll-based and physics-based animations.
- **ScrollTrigger:** Synchronizing the story flow with user scrolling.
- **Tailwind CSS:** For layout and typography.
- **SVG:** Detailed, handcrafted vector assets for lanterns and the boat scene.

## 🚀 Getting Started

1. **Clone the repository**
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run in development mode:**
   ```bash
   npm run dev
   ```
4. **Build for production:**
   ```bash
   npm run build
   ```
