# 🏮 Birthday Lantern Story: Development Mandate

This file serves as the foundational project instructions and persistent context for all AI agents working on this repository.

## 🏗 Architectural Foundation

- **Framework:** Vue 3 (Composition API).
- **Animations:** GSAP (GreenSock Animation Platform) + ScrollTrigger for scroll-based storytelling.
- **Visual Assets:** Primarily handcrafted SVGs to ensure high performance and mobile responsiveness.
- **Styling:** Tailwind CSS for utility-first styling.

## 🎨 Design Philosophy & Conventions

- **Aesthetic:** Fairytale/Storybook style. Soft parchment textures, warm amber glows, and deep indigo-violet backgrounds.
- **Mobile-First:** Every feature MUST be optimized for touch interactions and vertical scrolling.
- **Typography:** 
    - Headers: 'Cinzel', serif
    - Accents/Romantic Script: 'Great Vibes', cursive
    - Body: 'Quicksand', sans-serif
- **Characters:** Maintain anonymity. Use elegant, undetailed black silhouettes for Rapunzel and Flynn to keep the scene universal.
- **Lanterns:** Always cylindrical in shape. Avoid "cheap" gradients; use premium solid parchment tones with subtle internal halos.

## 🛠 Feature Specifications

### 1. The Lantern Story (Phases 2 & 3)
- Use a high density of letter lanterns (snippets).
- Ensure every snippet is correctly layered *inside* its cylindrical SVG lantern.
- Implement ambient, unpredictable swaying and flickering for all lanterns.

### 2. The Boat Scene (Phase 4)
- Maintain a highly elegant, self-contained SVG asset.
- Coordinate water reflections and castle silhouettes to create massive scale and depth.

### 3. Audio Integration
- Use "I See the Light" MP3.
- Smooth fade-in on the first user scroll is mandatory for browser compliance.

## 📜 Development Workflows

- **Verification:** Always test on mobile screen simulations.
- **Documentation:** Maintain `README.md` and this `GEMINI.md` as the sources of truth for project vision.
- **Reference Alignment:** Regularly compare implementation against `reference.png` in the project root.
